# DiabetesBurdenDashboard
Global Diabetes Burden and Treatment Outcomes Dashboard - MSBA382 Healthcare Analytics Individual Project

A single-page set of **coordinated, adjacent interactive graphs** (not a series of separate charts).
Clicking a country on the map or ranking bar, an age group, or a gender on any chart cross-filters
every other graph and the KPIs at once (brushing & linking / coordinated multiple views). Use
"Reset selection" to clear the linked selection. Requires Streamlit >= 1.35 for chart selection events.
